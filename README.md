# Recuperación de opiniones y clasificación de sentimiento en Steam
Nota: El documento se encuentra en este github llamado **proyecto_PLN (1)**
La etapa I devuelve reseñas relevantes para una consulta. La etapa II predice si el autor recomienda el juego a partir del texto de cada reseña recuperada. El identificador `review_id` permite seguir el mismo documento desde el corpus original hasta su predicción. El informe está disponible en [PDF](main.pdf) y en [LaTeX](main.tex).

## Etapa II · Preparación de datos y pipeline

1. [localizar_corpus y preparar_datos](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/experimentos.py#L82-L145) leen `opinions_raw_corpus.tsv`, comprueban calificaciones, textos vacíos y duplicados, y convierten la recomendación a `positive` o `negative`. Se conserva `document_id = review_id`. La entrada al modelo es `text = review` y la calificación queda como metadato.
2. [Partición estratificada](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/experimentos.py#L112-L125) divide las 600 reseñas con semilla 0 en 420 de entrenamiento, 90 de desarrollo y 90 de prueba. Ambas clases están presentes en cada conjunto. La auditoría y los conteos se consultan en [verificacion_datos.tsv](codigo_etapa2/resultados/verificacion_datos.tsv) y [distribucion_clases.tsv](codigo_etapa2/resultados/distribucion_clases.tsv).
3. [construir_pipeline](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/preprocesamiento.py#L495-L519) conecta normalización, vectorización y clasificador. Cuando se eligen léxicos o emojis, `FeatureUnion` concatena sus columnas con el vector de palabras. [Registro.correr](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/experimentos.py#L188-L200) ajusta el pipeline con entrenamiento y predice sobre desarrollo.

## Dónde se decide el mejor modelo

- **Dentro de cada familia**, [mejor y decidir](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/experimentos.py#L226-L238) eligen por macro-F1 de desarrollo redondeado a cuatro decimales. En empate conservan el ensayo con identificador anterior.
- **Entre familias**, [selección final en main](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/experimentos.py#L526-L539) compara primero macro-F1 y después F1 negativo. C080 y C125 empataron en ambas métricas (0.8113 y 0.6667). Por el orden de recorrido se seleccionó C080, regresión logística con contracciones, frecuencias de unigramas, Hu y Liu, SentiWordNet y `C=1`. La configuración está en [config_final.json](codigo_etapa2/modelos/config_final.json).
- **Evaluación final**, [reajuste y prueba](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/experimentos.py#L672-L704) entrena la configuración congelada con entrenamiento y desarrollo. En las 90 reseñas de prueba obtuvo macro-F1 de 0.7411. Los resultados por clase y las matrices están en [classification_metrics.tsv](codigo_etapa2/resultados/classification_metrics.tsv). Para rastrear un error, busca el `document_id` en [classification_predictions.tsv](codigo_etapa2/resultados/classification_predictions.tsv) y contrástalo con [analisis_errores_dev.tsv](codigo_etapa2/resultados/analisis_errores_dev.tsv) para los casos anotados de desarrollo.

## Ejecutar desde la raíz de este repositorio

```bash
python -m pip install -r codigo_etapa2/requirements.txt
python codigo_etapa2/interfaz.py clasificar "not worth the money"
python codigo_etapa2/interfaz.py buscar "cheaters" --sentimiento negative
python codigo_etapa2/interfaz.py metricas
python codigo_etapa2/interfaz.py errores
```

[cargar_modelo](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/interfaz.py#L39-L57) recupera el pipeline guardado. [buscar](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/interfaz.py#L82-L114) recupera reseñas, predice el sentimiento y filtra antes de tomar los primeros resultados. Si la aplicación de etapa I no está disponible, se usa la [búsqueda TF-IDF de respaldo](https://github.com/UlisesACC/proyecto-PLN/blob/cdc271d4ab6c87c386ffd07dd7c109417e5a5a62/codigo_etapa2/interfaz.py#L68-L80).

Para reproducir los experimentos, descarga el [TSV original de etapa I](https://github.com/UlisesACC/proyecto_1_PLN_/blob/b12210a3745a6119c9f3b19d9e1372b0c4a319c8/opinions_raw_corpus.tsv) y colócalo en la raíz o en `codigo_etapa2/`. Ejecuta `python codigo_etapa2/experimentos.py --sin-test` para desarrollo. La ejecución sin esa opción también reajusta el modelo seleccionado, evalúa prueba y escribe los resultados finales. Las versiones están en [entorno.txt](codigo_etapa2/resultados/entorno.txt).
